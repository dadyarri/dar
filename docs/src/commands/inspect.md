# Команда inspect

Открывает интерактивный TUI-браузер содержимого архива `.dar`.

## Синтаксис

```
dari inspect -f <файл> [опции]
dari -i -f <файл> [опции]
```

## Опции

| Флаг                                | Описание                                                              |
|-------------------------------------|-----------------------------------------------------------------------|
| `-f`, `--file <файл>`               | Путь к архиву (обязательно)                                           |
| `--encrypt-passphrase <PASSPHRASE>` | Парольная фраза для предпросмотра зашифрованных файлов                |
| `-h`, `--help`                      | Показать справку                                                      |

## Интерфейс TUI

После запуска открывается интерактивный экран с деревом файлов архива. Директории
можно разворачивать и сворачивать, файлы — просматривать.

### Навигация и управление

| Клавиша                        | Действие                                                                            |
|--------------------------------|-------------------------------------------------------------------------------------|
| `↑` / `k`                      | Переместить курсор вверх                                                             |
| `↓` / `j`                      | Переместить курсор вниз                                                              |
| `Enter` / `Пробел`             | Развернуть / свернуть директорию                                                    |
| `m`                            | Открыть / переключиться на / закрыть панель **Метаданные**                          |
| `c`                            | Открыть / переключиться на / закрыть панель **Содержимое** (предпросмотр файла)     |
| `Esc`                          | Закрыть активную панель предпросмотра                                               |
| `/`                            | Активировать нечёткий поиск по именам файлов                                        |
| `s`                            | Активировать поиск по метаданным (синтаксис `тег:значение`)                         |
| `q` / `Q` / `Ctrl+C`           | Выйти из TUI                                                                        |

### Прокрутка предпросмотра

Когда панель предпросмотра получает фокус (открыта), прокрутка её содержимого
осуществляется следующими клавишами:

| Клавиша    | Действие                    |
|------------|-----------------------------|
| `↑`        | Прокрутить вверх на 1 строку |
| `↓`        | Прокрутить вниз на 1 строку  |
| `PageUp`   | Прокрутить вверх на 10 строк |
| `PageDown` | Прокрутить вниз на 10 строк  |

### Поиск по именам файлов (`/`)

Нажатие `/` активирует строку поиска внизу экрана. По мере ввода список файлов
фильтруется с использованием нечёткого алгоритма (nucleo_matcher). Нажатие `Enter`
фиксирует фильтр; `Esc` сбрасывает его и восстанавливает полный список.

### Поиск по метаданным (`s`)

Нажатие `s` активирует поиск по дополнительным полям. Синтаксис запроса:

```
тег:значение
```

Допускается несколько условий через пробел (логика AND):

```
artist:Pink Floyd album:Wall
```

#### Доступные теги

| Псевдоним | Внутренний ключ | Описание                          |
|-----------|-----------------|-----------------------------------|
| `artist`  | `aar`           | Исполнитель (аудио)               |
| `album`   | `aal`           | Альбом (аудио)                    |
| `title`   | `atl`           | Название трека (аудио)            |
| `genre`   | `agn`           | Жанр (аудио)                      |
| `make`    | `imk`           | Производитель камеры (EXIF)       |
| `model`   | `imd`           | Модель камеры (EXIF)              |
| `date`    | `idt`           | Дата создания (EXIF)              |

Нажатие `Esc` сбрасывает поисковый запрос и восстанавливает полный список.

### Иконки Powerline / Nerd Font

**dari** автоматически определяет, поддерживает ли терминал глифы Powerline / Nerd
Font, и использует их для отображения иконок файлов и директорий. Определение
происходит в следующем порядке (первое совпадение побеждает):

1. `DARI_ICONS=1` (или `true`, `yes`) — явное включение; любое другое значение отключает.
2. Переменная окружения `WEZTERM_EXECUTABLE` присутствует → WezTerm.
3. Переменная окружения `KITTY_WINDOW_ID` присутствует → Kitty.
4. `TERM_PROGRAM` ∈ `{iTerm.app, WezTerm, Hyper}`.
5. `TERM` содержит `kitty` или `alacritty`.

Если ни одно условие не выполнено, используются стандартные символы (`▼`/`▶`).

## Примеры

```sh
# Открыть TUI-браузер архива
dari inspect -f out.dar

# Открыть с поддержкой предпросмотра зашифрованных файлов
dari inspect -f out.dar --encrypt-passphrase "secret"
```
