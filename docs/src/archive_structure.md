# Описание структуры архива

## Используемые типы данных

- _[BYTE]_ - базовый тип для хранения символа.
- _[BYTEARRAY]_ - последовательность _[BYTE]_. Её длина должна быть определена в другом месте.
- _[STRING]_ - строка. В **dari** используются строки, закодированные в UTF-8.
- _[INTEGER]_ - все целые числа, которые занимают больше одного байта, должны быть записаны в порядке от младшего к
  старшему
  без указания знака, если не сказано обратного.

## Элементы архива

Архив состоит из заголовка (HEADER), набора данных (DATA), индекса (INDEX)
и футера (FOOTER).

### HEADER (всегда 13 байт)

| Поле                 | Размер  | Примечание                                 |
|----------------------|---------|--------------------------------------------|
| Подпись              | 4 байта | Всегда равна `\x44\x41\x52\x49`            |
| Версия               | 1 байт  | Версия архива. На данном этапе равна **5** |
| Дата создания архива | 8 байт  | Unix Epoch time                            |

### DATA

Последовательный набор байт сжатых файлов

### INDEX

Информация о каждом файле в архиве (минимум 73 байта на каждый элемент):

| Поле                       | Размер     | Примечание                                                                          |
|----------------------------|------------|-------------------------------------------------------------------------------------|
| Отступ                     | 4 байта    | Количество байт отступа от начала блока данных                                      |
| Битовые флаги              | 2 байта    | Зарезервировано для будущего использования                                          |
| Метод сжатия               | 1 байт     | 0 - Без сжатия; 1 - Deflate; 2 - Zstandard; 3 - LZMA2; 4 - Brotli.                  |
| Дата изменения файла       | 8 байт     | Unix Epoch time                                                                     |
| ID пользователя владельца  | 4 байта    | ID пользователя (Unix). Если архив создавался на не-Unix системах всегда равен 1000 |
| ID группы владельца        | 4 байта    | ID группы (Unix). Если архив создавался на не-Unix системах всегда равен 1000       |
| Разрешения                 | 2 байта    | Разрешения файла (Unix). Если архив создавался на не-Unix системах всегда равен 644 |
| Контрольная сумма          | 32 байта   | Хеш несжатого файла. Используется алгоритм BLAKE3                                   |
| Оригинальный размер файла  | 4 байта    | Размер файла до сжатия                                                              |
| Размер сжатого файла       | 4 байта    | Размер файла после сжатия                                                           |
| Длина пути                 | 4 байта    | Количество символов в относительном пути файла                                      |
| Длина дополнительных полей | 4 байта    | Количество символов в блоке дополнительных полей                                    |
| Путь                       | переменный | Относительный путь файла внутри архива                                              |
| Дополнительные поля        | переменный | Набор пар ключ-значение в формате `KEY1=VALUE,KEY2=VALUE`                           |

### FOOTER (всегда 15 байт)

Служебная информация

| Поле              | Размер  | Примечание                                         |
|-------------------|---------|----------------------------------------------------|
| Подпись           | 7 байт  | Всегда равна `\x44\x41\x52\x49\x45\x4E\x44`        |
| Отступ до индекса | 4 байта | Количество байт от начала архива до начала индекса |
| Количество файлов | 4 байта | Количество файлов, находящихся в архиве            |
